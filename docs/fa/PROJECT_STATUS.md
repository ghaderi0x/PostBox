# وضعیت پروژه

## محیط نشست اول
در یک sandbox **بدون Flutter، بدون Dart و بدون شبکه** ساخته شد. دستورهای `flutter doctor`، `dart format`، `flutter analyze`، `flutter test` و هیچ بیلدی **اجرا نشده‌اند**. هیچ‌چیز با اجرا راستی‌آزمایی نشده است.

## نوشته‌شده (راستی‌آزمایی‌نشده)
مستندات، README، LICENSE، CI، pubspec، توکن‌ها و تم نارنجی، رابط و پیاده‌سازی موتور HTTP با آزمون‌ها، لوگو.

## انجام‌نشده
پوشه‌های پلتفرم، فونت‌ها، بومی‌سازی، تنظیمات، فازهای P1 به بعد، انتشار. هیچ پلتفرمی بیلد نشده است.

## گام‌های بعدی (روی دستگاه دارای Flutter)
1. `flutter create --org com.uniqueone --project-name postbox --platforms android,windows,linux .`
2. `flutter pub get` و ثبت `pubspec.lock`
3. اجرای format، analyze، test و ثبت نتیجه دقیق اینجا
4. ادامه با P1
