# پژوهش رقبا

در ۲ نوامبر ۲۰۲۶ با جست‌وجوی وب انجام شد. حقایق محصول تا جای ممکن از مستندات یا مخزن خود سازنده‌ها آمده است؛ جایی که فقط صفحه‌ای واسطه پیدا شد با *(ثانویه)* علامت خورده است. هیچ‌جا ادعا نشده PostBox از آن‌ها بهتر است: PostBox بنچمارک یا مطالعه کاربری ندارد. هدف این است که بدانیم توسعه‌دهنده از این ابزارها چه انتظاری می‌آورد.

## بررسی‌شده‌ها

| ابزار | مجوز / مدل | استفاده محلی بدون حساب | ذخیره‌سازی | پروتکل‌های ذکرشده |
|---|---|---|---|---|
| Postman | پلتفرم تجاری | بله، با «کلاینت سبک» هنگام خروج از حساب؛ کار روی دستگاه می‌ماند و پس از ورود می‌توان به فضای کاری برد. Scratch Pad منسوخ شده است. | فضای کاری ابری؛ ویژگی Git بومی در فهرست مستندات هست | HTTP، WebSocket، Socket.IO، GraphQL، gRPC، MQTT |
| Insomnia | کلاینت متن‌باز، حساب و پلن‌های پولی | بله، با Scratch Pad محلی | Local Vault، Scratch Pad، Cloud Sync (رمزنگاری سرتاسری)، Git Sync (طبق مستندات از پلن Team به بالا) | REST، GraphQL، WebSocket، SSE، gRPC |
| Bruno | MIT، نسخه‌های تجاری پولی هم دارد | بله: طراحی آفلاین، بدون حساب | مجموعه‌های متنی ساده (Bru) در یک پوشه و اشتراک با Git؛ README می‌گوید همگام‌سازی ابری برنامه‌ریزی نشده | REST و موارد دیگر (ثانویه: GraphQL، gRPC، WebSocket) |
| Hoppscotch | MIT، نسخه سازمانی برای برخی قابلیت‌ها (SSO) | برنامه وب میزبانی‌شده یا PWA؛ خودمیزبانی ممکن است | بک‌اند ابری یا خودمیزبان، آفلاین با PWA | REST، GraphQL، WebSocket، SSE، Socket.IO، MQTT؛ برنامه دسکتاپ و CLI (ثانویه) |

## معنای این برای PostBox

۱. **«اول محلی» انتظار شناخته‌شده‌ای است.** سه ابزار از چهار ابزار حالت بدون حساب دارند؛ Bruno آن را کل محصول کرده است. موضع «بدون حساب، بدون بک‌اند، بدون تله‌متری» عادی است، نه تمایز.
۲. **ذخیره‌سازی سازگار با Git شکاف اصلی است.** Bruno و Insomnia مجموعه‌ها را فایلی می‌بینند که می‌تواند در Git باشد. PostBox مجموعه‌ها را در SQLite نگه می‌دارد و خروجی/درون‌ریزی (JSON خود PostBox، Postman v2.1) دارد. قالب فایلی برای نسخه‌های بعد کاندید است؛ ساخته نشده.
۳. **پوشش پروتکل‌ها.** gRPC و MQTT در دو ابزار از چهار ابزار هست. PostBox HTTP، SSE، WebSocket و GraphQL را دارد؛ gRPC و MQTT برای 0.4 برنامه‌ریزی نشده.
۴. **انتخاب ذخیره‌سازی برای کاربر دیده می‌شود.** Insomnia اجازه می‌دهد برای هر پروژه محلی، ابری یا Git انتخاب شود. فضاهای کاری PostBox (0.4) فقط محلی‌اند؛ همگام‌سازی بیرون از محدوده v1 است.
۵. **اسکریپت انتظار می‌رود.** Postman و Bruno اسکریپت اجرا می‌کنند. PostBox به‌جای JavaScript زبان کوچک و جعبه‌شنی خودش را دارد (`SCRIPTING.md`)؛ کاربرانی که از JavaScript مهاجرت می‌کنند باید بازنویسی کنند و اسکریپت‌های درون‌ریزی‌شده هرگز اجرا نمی‌شوند.

## محدودیت‌های این پژوهش

- دور کوتاه: چهار ابزار، بدون آزمایش عملی، بدون مقایسه قیمت (پلن‌ها زود عوض می‌شوند).
- پایگاه شکایت ساخته نشد. پایگاه درست نیاز به خواندن منظم ردیاب‌ها و انجمن‌ها با تاریخ دارد.
- شمار ستاره‌ها، شمار کاربران و ادعاهای «بهترین» صفحات واسطه استفاده نشد.
