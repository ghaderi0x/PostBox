# ویرایشگر سفارشی

یک ویجت (`ui/editor/code_editor.dart`) برای بدنه درخواست، کوئری و متغیرهای GraphQL و نمایش متن بزرگ (فقط‌خواندنی) به‌کار می‌رود.

## پشتیبانی‌شده

رنگ‌آمیزی JSON و XML/HTML و برجسته‌سازی `{{متغیرها}}`؛ شماره خط (با شکستن خط هم درست)؛ تورفتگی خودکار، باز کردن `{}` و `[]` با Enter، Tab/Shift+Tab؛ تطبیق پرانتز و بستن/عبور خودکار در JSON؛ جستجو و جایگزینی با regex (`$1`..`$9`)، حساسیت به حروف، شمارش، قبلی/بعدی (Ctrl+F)؛ رفتن به خط (Ctrl+G)؛ واگرد/ازنو؛ اعتبارسنجی JSON با خط و ستون، زیرخط موجی و پیام قابل کلیک؛ قالب‌بندی و فشرده‌سازی JSON. جهت متن: JSON همیشه چپ‌به‌راست؛ متن ساده با اولین حرف قوی تعیین می‌شود.

## پشتیبانی‌نشده

- **تاخوردن کد (folding):** پیاده‌سازی نشده.
- **رندر مجازی در حالت ویرایش:** کل متن چیده می‌شود؛ بالای ۳۰۰٬۰۰۰ نویسه رنگ‌آمیزی خاموش می‌شود. برای پاسخ‌های بزرگ فقط‌خواندنی از `LinesView` (خطوط مجازی بدون رنگ) استفاده می‌شود؛ ستون شماره خط بالای ۵۰۰۰ خط پنهان است.
- چند‌مکان‌نما، تکمیل خودکار، قطعه‌کد، زیباسازی XML.
- هنگام ترکیب IME رنگ‌آمیزی موقتاً متوقف می‌شود.

## وضعیت صادقانه

منطق آزمون واحد دارد و چند آزمون ویجت هست؛ اما تایپ و caret با صفحه‌کلید واقعی و متن مخلوط فارسی/انگلیسی هنوز باید دستی آزموده شود.
