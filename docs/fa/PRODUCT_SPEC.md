# مشخصات محصول PostBox

PostBox یک کلاینت متن‌باز و محلی‌محور برای HTTP از Uniqueone است. برای کارهای محلی نیازی به حساب کاربری، سرور یا اینترنت نیست.

**پلتفرم‌ها:** اندروید، ویندوز، لینوکس. **زبان‌ها:** انگلیسی و فارسی (راست‌به‌چپ واقعی). **مجوز:** MIT.

## وضعیت قابلیت‌ها
- موتور HTTP: بخشی پیاده‌سازی شده (هسته P2، بدون اجرا و راستی‌آزمایی)
- سیستم طراحی: فقط توکن‌های نارنجی روشن و تیره
- فضای کاری درخواست، بازرس پاسخ، ویرایشگر سفارشی: برنامه‌ریزی‌شده (P3)
- مجموعه‌ها و تاریخچه: برنامه‌ریزی‌شده (P4)
- محیط‌ها و رمزها: برنامه‌ریزی‌شده (P5)
- احراز هویت و OAuth2 PKCE: برنامه‌ریزی‌شده (P6)
- درون‌ریزی/برون‌بری: برنامه‌ریزی‌شده (P7)
- قابلیت‌های پیشرفته: برنامه‌ریزی‌شده (P8)
