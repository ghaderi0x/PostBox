# سیستم طراحی

- **توکن‌ها:** فقط معنایی؛ ویجت‌ها از `context.colors` استفاده می‌کنند.
- **تم‌ها (هدف):** PostBox Orange (پیش‌فرض)، Midnight، Arctic، Emerald، Violet، High Contrast. پیاده‌سازی‌شده: نارنجی روشن و تیره.
- **فونت‌ها:** وزیرمتن (فارسی)، Inter (رابط)، JetBrains Mono (کد). هنوز بسته‌بندی نشده‌اند.
- **آیکون‌ها:** فقط یک کتابخانه؛ بدون نمادهای یونیکد.
- **چیدمان:** دسکتاپ با نوار کناری، فضای کاری و بازرس؛ اندروید با ناوبری فشرده و bottom sheet.
- **لوگو:** `assets/branding/logo.svg`، قابل جایگزینی آسان.
