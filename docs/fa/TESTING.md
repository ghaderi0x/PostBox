# آزمون

- `dart format --output=none --set-exit-if-changed .`
- `flutter analyze`
- `flutter test`

آزمون‌های فعلی: موتور HTTP روی سرور محلی (GET، POST، بریدن پاسخ، timeout، لغو، ریدایرکت و حذف سرآیند حساس، حلقه ریدایرکت، اتصال ردشده) و وجود توکن‌های تم.

هنوز آزمون **نشده**: خطای TLS، پروکسی، پاسخ‌های بسیار بزرگ، مهاجرت Drift، ویرایشگر و شکل‌دهی متن فارسی.
