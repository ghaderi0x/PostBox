# PostBox Script

اسکریپت‌های پیش از درخواست و پس از پاسخ با **PostBox Script** نوشته می‌شوند؛ زبان کوچکی که خود برنامه آن را تفسیر می‌کند. عمداً JavaScript نیست: موتور JavaScript، `eval`، بارگذاری کد، و دسترسی به فایل، سوکت، کلیپ‌بورد، سیستم‌عامل یا رمزهای برنامه وجود ندارد.

اسکریپت را می‌توان به درخواست (زبانه Scripts)، پوشه یا مجموعه (منو > احراز هویت، هدرها و اسکریپت‌ها) وصل کرد.

## ترتیب اجرا

۱. اسکریپت پیش از مجموعه، پوشه‌ها (از بیرونی‌ترین) و سپس اسکریپت درخواست.
۲. درخواست ارسال می‌شود.
۳. استخراج‌ها و assertionهای درخواست ارزیابی می‌شوند.
۴. اسکریپت پس از پاسخِ درخواست، سپس پوشه‌ها (از درونی‌ترین) و در آخر مجموعه.

خطا در اسکریپت پیش از درخواست مانع ارسال می‌شود و خطا با شماره خط نشان داده می‌شود. خطا در اسکریپت پس از پاسخ، پاسخ را نگه می‌دارد و در زبانه Tests گزارش می‌شود.

## زبان

```
// توضیح
let name = "value";            // متغیر (با دامنه بلوک)
name = name + "!";             // انتساب (متغیر باید از قبل باشد)
if (x > 1) { ... } else if (x == 1) { ... } else { ... }
for item in [1, 2, 3] { ... }   // فهرست یا کلیدهای یک شیء
```

- مقادیر: عدد، رشته، `true`، `false`، `null`، فهرست `[1, 2]`، شیء `{"a": 1}`.
- عملگرها: `+ - * / %`، `== !=`، `< <= > >=`، `&& || !`، `??`.
- دسترسی: `list[0]`، `obj.key`، `obj["key"]`، `text.length`.
- روش‌های رشته: `contains startsWith endsWith toUpperCase toLowerCase trim split replace substring`؛ فهرست: `contains join push`؛ شیء: `has keys`.
- `==` اعداد، رشته‌ها، فهرست‌ها و شیءها را بر اساس مقدار مقایسه می‌کند. `0`، رشته خالی، `null` و `false` در شرط نادرست‌اند.
- نقطه‌ویرگول اختیاری است. تابع، کلاس، `while` و import وجود ندارد.

## شیءها و توابع

| نام | کجا | کار |
|---|---|---|
| `vars.get(name)`، `vars.has(name)` | هر دو | خواندن متغیر. **متغیرهای محرمانه `null` خوانده می‌شوند.** |
| `vars.set(name, value)` | هر دو | تعیین متغیر (غیرمحرمانه). مانند استخراج ذخیره می‌شود: در محیط فعال یا سراسری؛ اجراکننده آن را برای هر تکرار در حافظه نگه می‌دارد. اسکریپت می‌تواند متغیر محرمانه را بازنویسی کند اما هرگز نمی‌خواند. |
| `request.method`، `request.url`، `request.body` | پیش: خواندن/نوشتن، پس: خواندن | `body` فقط برای JSON، متن، raw و GraphQL قابل نوشتن است. |
| `request.headers.get/set/remove/has` | پیش: خواندن/نوشتن | بدون حساسیت به حروف. |
| `response.status`، `response.reason`، `response.time`، `response.size`، `response.url`، `response.body` | پس از پاسخ | اطلاعات پاسخ. |
| `response.json()`، `response.text()`، `response.header(name)` | پس از پاسخ | اگر بدنه JSON نباشد `json()` خطای اسکریپت است. |
| `test(name, condition)` | هر دو | افزودن نتیجه آزمون (در Tests و اجراکننده). |
| `log(...)` | هر دو | افزودن خط به گزارش اسکریپت (۲۰۰ خط). |
| `fail(message)` | هر دو | توقف اسکریپت با خطا. |
| `now()`، `uuid()`، `str`، `num`، `len`، `json`، `parseJson` | هر دو | زمان، شناسه، تبدیل‌ها. |
| `base64`، `base64decode`، `urlencode`، `sha256`، `hmacSha256(key, message)` | هر دو | کمک برای امضا و کدگذاری. |

## محدودیت‌ها

طول اسکریپت ۱۰۰٬۰۰۰ نویسه؛ ۵۰٬۰۰۰ گام ارزیابی؛ ۲ ثانیه زمان اجرا؛ رشته تا ۱٬۰۰۰٬۰۰۰ نویسه؛ فهرست تا ۱۰٬۰۰۰ عضو؛ ۲۰۰ متغیر در هر اجرا. چون `while` نیست و حلقه فقط روی فهرست موجود می‌چرخد، حلقه بی‌پایان ممکن نیست؛ محدودیت گام و زمان خط دفاع دوم است.

## نکات امنیتی

- اسکریپت رمزی نمی‌بیند: متغیر محرمانه `null` است و توکن‌های احراز هویت در دسترس نیستند.
- اسکریپت به فایل، شبکه یا پردازه دسترسی ندارد.
- **اسکریپتی که درون یک فایل می‌آید هرگز درون‌ریزی یا اجرا نمی‌شود.** درون‌ریزی PostBox و Postman بلوک‌های اسکریپت را حذف می‌کند و در پیش‌نمایش می‌گوید. اسکریپت را خودتان پس از بررسی اضافه کنید.
- اسکریپت‌هایی که خودتان نوشته‌اید هنگام ارسال خودکار اجرا می‌شوند و می‌توانند نشانی و هدرهای درخواست را تغییر دهند؛ اسکریپت مجموعه‌هایی را که خودتان ننوشته‌اید بررسی کنید.

## تفاوت با JavaScript

تابع و closure، `while`، `===`، عبارت منظم و تاریخ (جز `now()`) نیست. اسکریپت‌های `pm.*` پستمن کار نمی‌کنند و تبدیل نمی‌شوند.
