# امنیت

- اعتبارسنجی TLS به‌صورت پیش‌فرض روشن است و غیرفعال‌کردن آن فقط با انتخاب صریح و نمایش هشدار ممکن است.
- سرآیندهای حساس (Authorization، Cookie) هنگام ریدایرکت بین مبدأها ارسال نمی‌شوند (دارای آزمون).
- حجم پاسخ محدود است و پاسخ‌های بزرگ بریده و علامت‌گذاری می‌شوند.
- رمزها فقط در حافظه امن؛ نه در تنظیمات، پایگاه‌داده متنی، لاگ یا خروجی پیش‌فرض.
- اسکریپت‌های درون‌ریزی‌شده هرگز اجرا نمی‌شوند. تله‌متری وجود ندارد.
