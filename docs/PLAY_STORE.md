# Google Play listing draft

## English

**Title (max 30):** PostBox: API Client

**Short description (max 80):** Open-source API client: collections, environments, OAuth 2.0. No account.

**Full description:**

PostBox is a fast, open-source HTTP API client that keeps everything on your device. Send requests, inspect responses, organise them in collections and run them as a suite, all without creating an account.

- GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS and custom methods
- JSON, form, multipart, raw and GraphQL bodies; Server-Sent Events and WebSocket
- Collections with folders, favorites, history and search
- Environments and variables, with secrets kept in the system keystore
- Basic, Bearer, API key and OAuth 2.0 (Authorization Code with PKCE)
- Assertions, request chaining and a collection runner
- Import cURL, Postman and OpenAPI (JSON); export cURL, Postman or PostBox files
- Syntax-highlighted JSON editor with find, replace and validation
- English and Persian (full right-to-left layout), six themes, light and dark

No ads. No analytics. No tracking.

## فارسی

**عنوان:** PostBox: کلاینت API

**توضیح کوتاه:** کلاینت API متن‌باز: مجموعه‌ها، محیط‌ها، OAuth 2.0. بدون حساب کاربری.

**توضیح کامل:**

PostBox یک کلاینت سریع و متن‌باز برای HTTP است که همه چیز را روی دستگاه شما نگه می‌دارد. درخواست بفرستید، پاسخ‌ها را بررسی کنید، آن‌ها را در مجموعه‌ها سازمان دهید و به‌صورت دسته‌ای اجرا کنید؛ بدون ساخت حساب کاربری.

- متدهای GET، POST، PUT، PATCH، DELETE، HEAD، OPTIONS و متدهای سفارشی
- بدنه JSON، فرم، چندبخشی، خام و GraphQL؛ رویدادهای ارسالی سرور (SSE) و وب‌سوکت
- مجموعه‌ها با پوشه، علاقه‌مندی‌ها، تاریخچه و جستجو
- محیط‌ها و متغیرها؛ رمزها در حافظه امن سیستم نگه داشته می‌شوند
- Basic، Bearer، کلید API و OAuth 2.0 (Authorization Code همراه با PKCE)
- ادعاها، زنجیره‌سازی درخواست‌ها و اجراگر مجموعه
- درون‌ریزی cURL، Postman و OpenAPI (JSON)؛ برون‌بری cURL، Postman یا فایل PostBox
- ویرایشگر JSON با رنگ‌آمیزی، جستجو، جایگزینی و اعتبارسنجی
- فارسی و انگلیسی (چیدمان کامل راست‌به‌چپ)، شش تم، روشن و تیره

بدون تبلیغات. بدون تحلیل رفتار. بدون ردیابی.
